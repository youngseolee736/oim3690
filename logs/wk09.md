## AI interactions 2
- I asked ChatGPT how to give specific prompts or rules to each AI agent.
- ChatGPT suggested giving each agent a different role and limiting the information it could receive. For example, the Script Analyst could study the reference transcript, but the Scriptwriter only received the general storytelling patterns instead of the original transcript. The Originality Reviewer then compared the generated script with the reference and checked if it was too similar.
- I used this answer to make the agents work in order and prevent the Scriptwriter from directly copying the reference video.
